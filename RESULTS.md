# Initial model results

These results were generated by running `python src/train_model.py` on the included 240-row controlled dataset.

| Model | Held-out accuracy | Macro F1 |
|---|---:|---:|
| TF-IDF + Logistic Regression | 0.6833 | 0.6310 |
| TF-IDF + Linear SVM | 0.8333 | 0.8278 |

The selected model is TF-IDF + Linear SVM. The held-out test set contains 60 examples: 10 from each of the six labels. The split holds out two entire base-template groups per class, so the five variants of a given base template cannot be divided across train and test.

**Interpretation:** 83.3% is a promising result for this small controlled prototype, but it should not be presented as performance on arbitrary real-world code. There are only eight base templates per class, and the variants are transformations of those templates. The next important experiment is to add independently sourced, manually verified implementations and split by repository.

The complete per-class metrics and confusion matrix are in `results/metrics.json` and `results/confusion_matrix.png`.
